# What is inside `forecaster.pkl`

This file is generated by `python src/pipeline.py`. Don't edit it, rebuild it. It is a compressed Python pickle, so it can't be read in a text editor. This card lists what it holds. The numbers below are read from the pkl itself.

It holds 2 plants x 9 horizons x 3 quantiles (P10, P50, P90) = 54 LightGBM models, each using 41 input features, plus the thresholds the alert engine needs.

## How to check it

1. Rebuild it from the code and data in this repo: `python src/pipeline.py` (about a minute). Training uses the tuned settings in `reports/lgbm_params.json`, which notebook 05 produced.
2. The test-set scores in `reports/lgbm_results.csv` and notebooks 05 and 08 come from these same settings, so a rebuilt model reproduces them.
3. Only load a pkl you built yourself or got from this repo. Loading a pickle runs code.
